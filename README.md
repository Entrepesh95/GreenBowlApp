# a web application made with C# ASP.NET using MVC framework

this application was designed to eliminate the process of using excel spreadsheets for a supply chain food factory and instead check and control the entire system through this application,
which displays the quantities, control batches, resources, deliveries live, without the need to check excel spreadsheets and calculate amounts by hand, preventing human error and constantly checking excel files when a batch runs.

## Tech stack
- C# MVC framework ASP.NET
